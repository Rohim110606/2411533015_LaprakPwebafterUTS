Laporan Praktikum UI dan Bootstrap

A. PENDAHULUAN

Perkembangan teknologi informasi menuntut adanya sistem informasi yang mampu mengelola data secara efektif, efisien, dan terstruktur. Dalam pengembangan aplikasi berbasis web, framework Laravel menjadi salah satu pilihan yang banyak digunakan karena menyediakan berbagai fitur yang mempermudah proses pengembangan, seperti authentication, migration, seeding, routing, dan templating.

Pada praktikum kali ini akan kita lakukan implementasi antarmuka pengguna (User Interface/UI) menggunakan Bootstrap serta penerapan konsep templating pada framework Laravel 9 dalam studi kasus Sistem Informasi Sekolah. Kegiatan praktikum mencakup pembuatan proyek Laravel, konfigurasi database, penerapan fitur autentikasi, pembuatan layout aplikasi menggunakan template SB Admin 2, serta pengembangan fitur manajemen pengguna (CRUD). Melalui praktikum ini, mahasiswa diharapkan dapat memahami proses pembangunan aplikasi web yang memiliki tampilan menarik, terstruktur, dan mudah dikelola.

B. TUJUAN

  1. Mahasiswa mampu memahami proses implementasi fitur autentikasi pada Laravel menggunakan Laravel UI dan Bootstrap sehingga aplikasi memiliki sistem login, registrasi, serta manajemen pengguna yang aman dan terintegrasi.
  2. Mahasiswa mampu menerapkan konsep templating dan layouting pada Laravel untuk membangun antarmuka aplikasi yang konsisten, terstruktur, dan mudah dikembangkan menggunakan template Bootstrap.
  3. Mahasiswa mampu mengimplementasikan operasi CRUD (Create, Read, Update, Delete) pada data pengguna sebagai dasar pengelolaan data dalam aplikasi web berbasis Laravel.

C. ISI

Praktikum ini mencakup seluruh tahapan pengembangan aplikasi web modern dari setup awal hingga deployment dengan menggunakan best practice Laravel.

D. KESIMPULAN

Berdasarkan praktikum yang telah dilakukan, dapat disimpulkan bahwa Laravel mempermudah dan mempercepat pengembangan Sistem Informasi Sekolah. Fitur authentication memungkinkan kita membuat sistem login dan registrasi secara otomatis, sedangkan migration dan seeder memudahkan pengelolaan struktur database serta data awal pengguna.
