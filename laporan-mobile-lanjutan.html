Praktikum 4

PENDAHULUAN

Pengembangan aplikasi seluler sering kali membutuhkan pemindahan tampilan dari satu layar ke layar lainnya. Pada framework Flutter, proses perpindahan halaman dan pengiriman data diatur menggunakan konsep navigasi yang bekerja mirip seperti tumpukan kartu (stack). Melalui modul ini, mahasiswa diajar memahami bagaimana aplikasi dapat mengelola alur perpindahan antarlayar dengan rapi dan efisien.

Selain berpindah halaman, suatu aplikasi juga perlu saling berbagi atau mengirimkan data antarlayar, misalnya dari daftar transaksi menuju halaman detail. Pengiriman data ini dilakukan dengan memanfaatkan Constructor pada widget tujuan. Dengan memahami konsep ini, alur data di dalam aplikasi dapat berjalan secara dinamis dan terstruktur sesuai dengan interaksi pengguna.

Modul ini memberikan panduan praktis berupa pembuatan aplikasi pemantau keuangan (Expense Tracker) sederhana. Melalui pengerjaan kode secara langsung, mahasiswa dipandu untuk membuat struktur aplikasi multi-halaman yang modular, mulai dari halaman utama (Dashboard), halaman tambah transaksi, hingga halaman detail transaksi.

TUJUAN

  • Mahasiswa mampu menggunakan fungsi Navigator.push untuk membuka halaman baru serta Navigator.pop untuk menutup halaman dan kembali ke layar sebelumnya.
  • Mahasiswa mampu mengirimkan data (seperti teks judul, nominal, kategori, dan tanggal) dari satu halaman ke halaman lain menggunakan Constructor.
  • Mahasiswa mampu membagi dan merapikan kode program ke dalam beberapa file terpisah agar aplikasi lebih mudah dikembangkan dan dikelola.

ISI

1. Pertama-tama kita perlu membuat kodingan yang berfungsi untuk membuat aplikasi Flutter dengan MyApp sebagai widget utama dan DashboardScreen sebagai halaman pertama yang ditampilkan. MaterialApp mengatur tampilan dasar aplikasi, seperti menghilangkan banner debug.

2. Selanjutnya, kita buat kodingan yang berfungsi untuk membuat halaman Dashboard Keuangan yang menampilkan sapaan pengguna, saldo utama, daftar transaksi terakhir, serta tombol + untuk menambahkan transaksi baru. Fungsi buildBalanceCard() digunakan untuk menampilkan saldo, sedangkan _buildTransactionList() menampilkan daftar transaksi seperti makan siang dan gaji bulanan beserta jumlah, kategori, dan tanggalnya. Ketika tombol atau transaksi ditekan, Navigator.push() digunakan untuk berpindah ke halaman lain, termasuk mengirimkan data transaksi ke halaman detail.

3. Kemudian perlu kita buat kodingan yang berfungsi untuk membuat halaman Catat Transaksi yang memungkinkan pengguna memasukkan judul dan nominal transaksi melalui formulir. Form dan validator digunakan untuk memastikan data tidak boleh kosong sebelum disimpan, kemudian muncul pesan "Transaksi Berhasil Disimpan!" jika data valid. Setelah berhasil disimpan, Navigator.pop() digunakan untuk kembali ke halaman Dashboard sebelumnya.

4. Setelah itu buat kodingan yang berfungsi untuk membuat halaman Detail Transaksi yang menampilkan informasi transaksi seperti judul, nominal, kategori, tanggal, dan status. Data transaksi dikirim melalui constructor menggunakan parameter required, sehingga setiap informasi wajib tersedia ketika halaman dibuka. Fungsi _buildDetailRow() digunakan untuk membuat tampilan baris detail agar lebih rapi dan menghindari penulisan kode yang berulang.

TUGAS

1. Untuk membuat output seperti yang diinstruksikan, ada beberapa hal yang akan kita edit yaitu _selectDate, guna menampilkan dialog kalender (showDatePicker) dan mengformat tanggalnya ke DD/MM/YYYY.

2. Kemudian kita tambahkan kodingan yang berfungsi untuk menambahkan kolom input tanggal dengan fitur pemilihan kalender.

KESIMPULAN

Dari Praktikum kali ini dapat disimpulkan bahwa penguasaan fungsi navigasi (Navigator.push dan Navigator.pop) serta pengiriman data (passing data) melalui Constructor merupakan fondasi penting dalam membuat aplikasi Flutter yang interaktif dan dinamis. Dengan menerapkan pemisahan file yang rapi pada setiap halaman, aplikasi tidak hanya berjalan dengan baik saat berpindah layar dan menampilkan data detail, tetapi juga memiliki struktur kode yang bersih serta mudah dipelihara.
